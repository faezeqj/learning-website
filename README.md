## Features

- Fixed layout using Flexbox and CSS positioning
- Animated hero section with floating cards and a pulsing CTA button
- BEM naming convention (block__element--modifier) throughout
- Inline SVG icon sprite system
- Clean, minimal design for desktop view
> Note: This project is **non‑responsive**, designed for desktop screens only.

## Built With

- **HTML5**
- **CSS3**
- **Flexbox**
